        Open questions (P1-14), each with a recommendation

        1. Add panel place: a full-width strip above the patch table (sketched), not the 320 px side column, so three columns fit. Selected stays at the right.
        2. Search and browse are one: typing narrows the manufacturer column to makers with a match and the model column to matches; no separate result list.
        3. Mode column with channel counts: the index learns each mode's channel count while indexing (no conversion), so the third column reads "6 Channel · 6".
        4. "In this show" on top of the manufacturer column: the profiles already patched, for adding one more of the same.
        5. Save writes both: the user profile (wins over QLC+, LIB-12) and the show's copy for every fixture of that type, one undo step. A mode change that drops channels is refused here; the editor never changes footprints of patched modes.
        6. Slots per channel (the model already has them), not ONYX's separate wheels linked to a channel: one step instead of two. Split halves a range; Merge joins it with the next.
        7. Test puts the clicked slot's middle value (or the level being edited) into the programmer for the selected fixtures of this type: plain programmer values, Clear removes them. No new engine concept.
        8. Gobo pictures later with the icon library (IDEA-14); phase 1 slots carry a name and, on C channels, a colour.
        9. Lightkey slots typed by hand in this editor; a Lightkey importer stays out of scope until a file is studied.
