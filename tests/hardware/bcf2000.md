# BCF2000 checklist (CTL-01..04, ADR-003 mapping) — template

Setup: BCF2000 in **Mackie Control mode** (hold the leftmost encoder-group button
while powering on, pick preset "MC C" for Cubase/generic; see BCF manual), USB to
the Mac. Daemon running with the MCU driver.

- [ ] macOS Audio MIDI Setup shows "BCF2000" with in and out ports
- [ ] Fader 1 up → playback 1 level rises in the app and on DMX; full travel reads 0 % … 100 % (CTL-01)
- [ ] Page+ (right-hand button mapped to Bank ▶) → faders 1–8 motor to the new page's levels within ~0.3 s (CTL-02)
- [ ] Touch a fader without moving it: no level jump (fader touch is decoded, not treated as a move)
- [ ] Upper button row → Swop/Select; lower row → Flash; LEDs follow playback active state (CTL-03)
- [ ] Encoder 1 turned clockwise → engine receives positive deltas; LED ring follows the value (CTL-04)
- [ ] Encoder group buttons 1–4 switch wheel banks I+P / C / G+B / FX+S as proposed in ADR-003 — note here what the BCF actually sends for each group so the mapping can be fixed:
      group 1: ____  group 2: ____  group 3: ____  group 4: ____
- [ ] Power-cycle the BCF while the daemon runs: daemon logs the port loss, re-attaches on return, no crash
