# BCF2000 checklist — Mackie Control profile (VS1-07, CTL-01..04, 20, 21, 30..33)

Gate 3: only the owner ticks these. Copy to `tests/hardware/runs/<date>-VS1-07.md` for a run.

Setup: BCF2000 in **Mackie Control mode** (hold the leftmost encoder-group button while powering
on, pick preset "MC C"; see the BCF manual), USB to the Mac. Daemon running (`cargo run -p
cmdmx-daemon` or the app), demo show (`faders_per_page` 8, playbacks 1–8 on page 1).
Output visible on Art-Net (Claude listens) or in the app.

## Attach
- [ ] macOS Audio MIDI Setup shows the BCF2000 with in and out ports. Name as the daemon lists it: ________
- [ ] The device appears `Disabled`; `control.enable` (or the Control screen) enables it and it gets
      the mapping **Mackie Control** (`profile: true`) (CTL-24, 30)
- [ ] On enable the motor faders move to the levels of page 1 (all at 0 in the demo show) (CTL-21)

## Faders and pages
- [ ] Fader 1 up → playback 1 rises in the app and on DMX; full travel reads 0 % … 100 % exactly (CTL-01, 31)
- [ ] Faders 2–8 move playbacks 2–8; the master fader moves the Grand Master (CTL-33)
- [ ] Bank ▶ → page 2: the motor faders move to page 2's levels within ~0.3 s; Bank ◀ → back to
      page 1 and the motors return (CTL-21, 32)
- [ ] A page change on the screen moves the motors too (CTL-21)
- [ ] Touch a fader without moving it: no level jump; hold it while the level changes on the screen:
      the motor does not fight the hand; at release it snaps to the engine level (CTL-20)
- [ ] Set `faders_per_page` 10 in a show: Channel ▶ puts slots 9–10 on faders 1–2 and faders 3–8 go
      to 0 and do nothing; Channel ◀ goes back (CTL-31, 32)

## Buttons and encoders
- [ ] Top button row (REC) of channel 1 → playback 1's upper button (Flash); its LED follows (CTL-33)
- [ ] SELECT row of channel 1 → playback 1's lower button; its LED follows
- [ ] V-Pot 1 turned with a fixture selected → wheel 1 moves (positive = clockwise); its ring shows
      the value as one dot (CTL-04, 33)
- [ ] V-Pot 1 push → Fix ▶ (`key step_next`)
- [ ] Play → Go, Stop → Stop, Rewind → Back on the connected cue list
