# Keys off says so, and an armed function's message goes — NEW-02, NEW-03 (2026-11-04)

`tests/manual/app-main-screen.md` *Keys off says so* (UI-49) and *An armed function's message goes with it* (UI-50), at home without lamps.
Claude drove the app with a real mouse and real keys by full-screen control; the owner approved it. Background keys do not reach the key monitor. A small WebSocket client seeded the palettes and sent commands as a second client.

Setup: this branch on `main` with #238, debug bundle, app with `-consoleMode NO -keysLive NO` (and once `YES`), against a daemon with `--demo`, `--show-dir` and `--profiles-dir` in a temp folder and `--no-sacn --no-serial`. Palettes 1 and 2 in Colours.

## Keys off (UI-49)
- [x] Workspace: `1`, `f`, Return, Backspace, Up and Space each say "The Mac keyboard is off: turn on Keys in the status bar, or use the keypad."; the line stays empty and no cue runs.
- [x] F2 says the same and stays on the workspace; on the Output screen too. A digit on the Output screen says nothing.
- [x] `x` says nothing. ⌘2 switches workspace and says nothing. Esc does its own work.
- [x] A click on the command line says the same. With `-keysLive YES` it says nothing, and `4`, `2` fill the line.
- [x] A digit in the Patch search field and in the Set Legend sheet's field types there, with no message. In the Lock prompt it goes to the code.
- [x] The Messages count stays at what the warnings gave: 1 after the first warning, after all the keys above.

## Armed function (UI-50)
- [x] Delete's hint goes with Esc, the keypad's Exit, the Cancel softkey and the Output screen opening.
- [x] Delete, palette 2: "Delete palette 2? No cue uses it. Confirm on softkey A."; softkey A: the palette and the message go.
- [x] Delete, an empty cell: "Delete: that cell is empty."; Exit: it goes.
- [x] Copy, palette 1: "Copy palette 1: tap an empty cell."; the empty cell: the copy is made and the message goes.
- [x] Delete then Record: no hint stays. Delete then Copy: Copy's hint replaces it.
- [x] Record, a used cell: "Palette 1 is used: …"; Cancel: it goes.
- [x] Set Legend's hint, a tap on a palette, Cancel in the sheet: it goes.
- [x] Delete armed, then a warning ("nothing is selected" by Locate, "invalid command" from a second client): it stays through the Cancel softkey, Exit and Esc.
- [x] Delete armed, then a notice ("Group 1", from a second client): it stays through Esc.
- [x] Delete armed, a digit with Keys off: UI-49's message replaces the hint and stays through Esc, as it is not the function's own.

## Not run
- A held key: the tool's key presses do not repeat, so `isARepeat` is by reading. The checklist line stays for a run by hand.
- Update and Move finishing, and the Cue softkeys' messages: they end in the same armed state, so the one `onChange` covers them; by reading.

## Seen
- A stray key with Keys off replaces what the message zone shows, as UI-49 asks, also an unread warning or a delete's count. Nothing is lost: the warning stays in the Messages count and sheet, and the softkey still says Confirm delete.
