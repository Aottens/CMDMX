## Experiments (each a temporary change, measured, then undone)
| Change | Idle | `--demo` |
|---|---|---|
| No live publishing at all (output and playbacks) | 6.8 % | 8.8 % |
| Only the strip cells publish | 5.3 % | 29.9 % |
| Only the stripe cells publish | 4.7 % | 30.1 % |
| Playback rebuild at 10 Hz instead of 30 | 7.4 % | 32.9 % |
| Only the visible workspace drawn (the others now stay built, at opacity 0) | 5.6 % | 28.9 % |
| … and no workspaces at all | 2.7 % | 29.2 % |
| … and no playback area | 4.4 % | 26.9 % |
| … and no side column and attribute bar | 0.8 % | 25.4 % |
| No right-click catcher (an NSView) per fixture tile | 2.1 % | 29.2 % |

Reading: any single live source redrawing one small view 20–30 times a second costs about 20 %, whatever zone it is
in, so each redraw has a fixed cost of about 8 ms. A `sample` puts it in SwiftUI's `NSHostingView.layout` →
`ViewGraphRootValueUpdater.render` → `DisplayList.ViewUpdater` and AppKit's `_findAnySubviewNeedingAutoLayoutEngine`,
not in CMDMX's own bodies. A bare SwiftUI app redrawing one bar at 60 Hz uses 0.4 %, so it is not the platform.

## Open points

- Drawing only the visible workspace saves 8 % but drops the hidden workspaces' state (scroll positions) → SNP-04
