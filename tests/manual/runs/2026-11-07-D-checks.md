## Checks
- [x] D1: every copy, move and delete takes one item. `playback.copy/move {id, page, slot}`, `playback.delete {id}`,
  `palette.copy/move {number, to}`, `palette.delete {number}`, `group.copy/move {group, to}`, `group.delete {group}` and
  `cue.copy {id, cue, to}`, `cue.delete {id, cue}` (`ipc.rs` `parse_command`) map to one-item engine methods
  (`copy_playback`, `move_playback`, `copy_palette`, `copy_group`, `copy_cue`). The app keeps one source
  (`ui.handleSource` in `PlaybackViews.swift`, `ui.source` in `PaletteWindows.swift`), and Delete waits on one target
  (`MainScreen.swift` `confirmDelete`). Nothing like Retain Layout or Bunch Up exists. Every action ends in
  `ui.cancelModes()`, so there is no Menu Latch. Holds.
- [x] D2: no command clears a page, a pool or a show while keeping the patch. The only clears are programmer clears.
  `show.new` builds `Engine::new(Settings::default())` (`main.rs`), which empties the patch too. There is no page copy.
  Holds.
- [x] D3: `playback.release` takes one `id`; without it, it releases the connected list (CUE-27). The control `Target`s
  are `Connected`, `Slot`, `PageSlot` and `Playback`; there is no page target and no "all" target. There is no
  `release_all` anywhere. Holds.
- [x] D4: Unfold in the app folds a fixture's cells only (UI-29). `copy_playback` clones the playback under a new id,
  with no link. `check_empty_handle` refuses a used target for both Copy and Move, so nothing swaps. Holds.

## Titan
Read on manual.avolites.com on 2026-11-07 (current manual, with 15.0 where a page differs). Pages:
- *Copying, Moving, Linking and Deleting a Cue List* and *... a Cue*
- *Copying, Moving and Deleting Palettes*
- *Organising the console* (15.0)
- *Clearing the Console* and *The System Menu*
- *Playback controls* and *Cue Playback*
- *Editing Cue Lists* and *Editing a Chase*

What Titan does:
- A range is picked by holding the first button and pressing the last, or with Thro and And.
- A block starts at the target. Retain Layout keeps gaps; Bunch Up closes them.
- A Move that does not fit, or has an item in the way, is not completed unless *Swap Items if Required* is on.
- Copy twice, or Link, makes a linked copy.
- Menu Latch keeps Copy, Move or Delete active.
- New Show and Wipe empty everything; the only thing they can keep is the DMX settings.
- Release twice releases all running playbacks, within the Release Priority setting.
- Release then a page offers *Release this Page*, *Release Playbacks Not On This Page* and a third choice per fader
  group.
- Unfold is a temporary edit view of a list's cues on the faders, not a copy.

What the pages do not say:
- What a Copy onto a used target does.
- Whether a range can be picked by dragging.
- Whether Unfold leaves anything behind.
- Anything about clearing a single page or pool.
