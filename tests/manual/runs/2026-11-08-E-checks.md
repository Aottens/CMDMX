## Checks
- [x] K1: done. `Generic` / `Dimmer` is built in (`cmdmx-daemon/src/library.rs`, LIB-40, NEW-01), with `lib_40_…` tests. Nothing to specify.
- [x] K10: holds, and is wider than the run saw. `AddPanel.add()` in `PatchView.swift` keeps every field: nothing empties `number`
  or `address` after an Add. The run's Address probably looked reset because it had been left empty; a typed one stays too.
- [x] M2: holds. There is no command that changes a fixture's profile: `patch_change_mode` looks a mode up in the fixture's own profile.
  Every reference uses the fixture's id (`Item.fixture`), so keeping the id keeps groups and cues. `apply_mode` is the model for
  dropping values. Its `keeps` rule compares name and kind, and has no slot rule: mode changes stay within one profile.
- [x] M2 palettes: `Palette.shared` is keyed by profile key, so a changed profile would lose shared values without PAT-39;
  `Palette.fixtures` is keyed by item and stays; `global` needs nothing.
- [x] M3: holds. `PatchView` has a `Table` with no filter under an `AddPanel` of fixed height 220. The Fixtures window's matcher
  (`FixturesWindow.matches`, UI-59) can be reused.
- [x] E1: none exists. `Fixture` has no behaviour fields; no invert, limit, offset or curve in `patch.rs`, `profile.rs` or the frame writer
  (`engine.rs` `write_value`, `write_cell`). The value passes through one place per attribute before the write, so the output stage has one home.
- [x] E2: no copy of a fixture, no address swap, no update from the library, no group made by a patch. `patch_remove` shows every place
  a fixture's data lives, which is the list PAT-40 has to copy. `Engine::save_profile` already holds LIB-25's checks for PAT-42.
- [x] E3: `Library` has save calls only; nothing removes a user profile. `library.save_profile` replaces (LIB-14), so a duplicate needs its own command.
- [x] E4: no lamp, macro or RDM code. Control channels with named slots exist (LIB-15) and can be set by hand. `cmdmx-protocols` has Art-Net, sACN and ENTTEC output only.

## Titan
Read on manual.avolites.com on 2026-11-08 (current manual, 19.0). Pages: *Changing the Patch*, *Copying, moving and deleting
fixtures*, *Fixture Personality Options*, *Patching new Fixtures or Dimmers*, *Fixture Groups*, *Changing Fixture Attributes*, *Fixture Advanced
Options*, *Fixture Personalities*, *Curves*.

What Titan does:
- Fixture Exchange: pick the new type in Patch, touch each fixture, choose Exchange Fixture. Pan, Tilt and Dimmer always carry over, the other functions are matched and adjustable in Exchange Mapping. Programming and palettes are preserved. Absolute values may need re-recording, and palettes an update.
- Swap Fixture Addresses: One For One (equal numbers) or Retain Layout.
- Update Personality: Patch, Edit Fixtures, select types or Update All. The show keeps its own copy until then.
- Copy: the new fixture comes with the cues and palettes of the original and starts Parked.
- Auto Groups: an *All <type>* group and one per patched quantity; off in User Settings.
- Options per fixture and attribute: Invert, Limits (programmer values may lie outside), Offset ("just before final output"), Curves, Freeze, Reset Behaviour (not the swap). Swap Pan and Tilt per fixture.
- Patch View filters by fixture type and line. The DMX address moves to the first free one as you patch.
- Flip: the other yoke position; its settings are "defined in the fixture personality". Fixture Macros run Lamp On, Lamp Off and Reset through the control channel.
- RDM: an RDM-enabled Art-Net node is required; XLR does not carry it.

What the pages do not say:
- What an exchange does to addresses, or to groups by name; whether it can be undone; whether unmapped functions are lost.
- Whether a copy joins groups.
- Auto Groups' default, its naming rule, and whether later patches add to them.
- Find or search in Patch View; whether the user number moves on after a patch.
- What the curves other than Linear do.
- What an inverted or limited value does to what is stored; PAT-45 follows Offset's "before final output" for all of them.
