## Fixes found in this run
- With fixtures selected, which an edit always has, the Selection softkeys hid *Save palette* and *Cancel*. The edit's
  softkeys now win over the Selection softkeys.
- Edit on palette 1 selected only 101: the palette is global with a shared White part, and `edit_palette` looked at the
  shared part first. It now reads the level from `Palette::kind()`, as the rest of the engine does; test
  `pal_36_a_global_palette_with_a_shared_part_is_global`.
