# Batch J checks (P1-43, 2026-11-15, after batch I)

Each point of IDEA-35 batch J was checked by reading the code on `main` (60fda6d) before its criteria were written, as
`2026-11-14-I-checks.md` did for I. J8 went into batch C (ENG-25, IPC-60, UI-57) and is not repeated. The third review added
K3, and K2 with J3; K2's hint and manual line were done before batch B (UI-49, P1-30), and Keys stays off by default (owner,
2026-11-04). The app was not run for this spec, and no test was run. TST-01 and DEF-06, found in runs of batches G and I, get
their criterion here too.

Titan was looked up in the v19 manual: *Changing Fixture Attributes*, *Front Panel Buttons* (the PC keyboard shortcuts),
*Using the Select Buttons and Wheels* (v14), *MIDI, DMX or Audio Triggering*, *Playback Paging* (summary only). The lookup
read summaries of those pages.

## Checks
- [x] J1: holds. The command grammar (`command.rs`) has a level, `Palette n` and `Lee n`; nothing types an attribute value.
  `programmer.set` (IPC-39) takes an absolute 0..1 value and is sent by the profile editor's Test only. Titan: in the Program
  menu, type a value on the keypad and press the attribute's softkey; a percentage for a mix attribute, the slot's index for a
  wheel such as colour or gobo (*Changing Fixture Attributes*). The @ beside a wheel opens *Adjust Attribute Value*.
- [x] J2: holds. A fixture tile tap selects one fixture (`Windows.swift`); no ⇧-click and no box. Titan: slide a finger across the
  touch buttons to draw a selection box; on the panel, hold the first Select and press the last (*Using the Select Buttons
  and Wheels*). The manual does not say in which order a box selects.
- [x] J3: holds. `MacKeys` (`TokenLine.swift`) gives the command-line keys, F1–F5, Space and Up/Down with Keys live, and
  Esc, ⌘L, ⌘Z, ⇧⌘Z, ⌘? and ⌘1–⌘5 whatever Keys says. There is no key for Clear, Record, Update, Delete, Copy, Move, Locate,
  Highlight, a softkey or a page, and the menu bar has only *CMDMX Manual* (`CMDMXApp.swift`). Titan PC: Alt+C Clear,
  Alt+D Delete, Alt+Shift+C Copy, Alt+M Move, Alt+Shift+U Update, Alt+R the Record menu, Alt+L Locate, Alt+I Include,
  Alt+Shift+R Release, Alt+U Unfold, Alt+G Go, Alt+1..7 softkeys A..G, Alt+Left/Right previous and next fixture, Alt+Up All,
  Alt+Down Highlight, numeric `/` Thru, `*` @, `-` Not, `+` And (*Front Panel Buttons*). No page key is listed.
- [x] J4: holds. The control vocabulary (`action.rs`, CTL-05) has `key clear|locate|highlight|rem_dim|undo|redo|all|step_*`
  and no record, update, delete, copy, move, legend, include, exit or lock. Arming is view state in the app (UI-42's note), so
  the daemon cannot arm anything. Titan: a MIDI trigger of type *Hardware* presses a physical or touch button as the key
  profile says (*MIDI, DMX or Audio Triggering*); the page does not name Record or the keypad.
- [x] J5: holds. The daemon keeps one keypad buffer for all surfaces (`control.rs`): a token is pushed, Backspace pops, Enter
  sends the line and empties it. Nothing shows the buffer, there is no `keypad Exit`, so a line left without Enter is the
  start of the next one.
- [x] J6: holds. `group <id>`, `palette <id>`, `playback <id> level` and `fader|upper|lower <page.slot>` address by number
  (`action.rs`); mappings, deck keys included, live per Mac (CTL-23) and are never told of a Move or Delete. `usage`
  (IPC-54) counts cues, groups and palettes, not controls. Titan's *Item* trigger names a programmed item; the manual does not
  say what a move does to it.
- [x] J7: holds. The pages column (`PlaybackArea.swift`, UI-21) shows number and legend only. Titan documents no mark on its
  page buttons; its *Active Playbacks* window lists running playbacks with their page, as ours does (PBK-40).
- [x] J9: holds. The daemon's stdout and stderr go to `~/Library/Logs/CMDMX/daemon.log` (REL-12), where a panic's message
  lands. The app names the path only in REL-28's steady line and has no way to show or reveal the file.
- [x] K3: holds. Colour is Fixtures, Picker, Colours, Programmer; Playbacks is Cues, Active, Fixtures, Programmer
  (`Windows.swift`); neither has Groups, so taking a group means another workspace or `Group n Enter`.
- [x] DEF-06: holds as the TTN-04, 06, 10 run found it: undo restores cues by number, so a running list whose current cue
  number is gone after the step stays on a number no cue has, and Go finds no next cue (UNDO-10 says nothing of it).
- [x] TST-01: holds as the FIL-01..03 run found it: `client_loss`, `lock`, `message_history` and `remote` start the daemon with
  the Demo show and Art-Net on, `message_history` with serial on too.
