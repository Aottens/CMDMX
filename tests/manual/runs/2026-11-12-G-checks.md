# Batch G checks (P1-41, 2026-11-12, after batch F)

written, as `2026-11-10-F-checks.md` did for F. The app was not run for this spec, and no test was run. Titan was looked up for
New Show, Load Show, Save As, show files and reports (*Loading and saving shows*, *Clearing the console*, *Show library*,
*DMX output mapping*, *Creating reports*).

## Checks
- [x] M1: holds. `Engine::new_keeping_patch` takes the patch, profiles, output and settings and empties groups, palettes, pages
  and playbacks (SHW-19). Effect palettes are palettes (schema 8), and group grids and legends live with the groups, so keeping
  `groups` and `palettes` keeps all of them. Titan's New Show keeps only the DMX settings; keeping more is our own choice.
- [x] G1: holds. The Show screen has Open, New (with *Keep the patch*) and Save As only (`ShowView.swift`); no command renames or
  deletes a show, and the app has no path to reveal.
- [x] G2: holds. `show.open` builds the engine from the file and `outputs.reconcile` runs on its nodes (`main.rs`), so the
  running output is replaced. Titan asks on Load Show whether to keep the console's DMX settings.
- [x] G3: holds, as specified (SHW-15): Save As continues in the copy. The manual does not say which show Titan works in after
  Save As.
- [x] G4: half. Open of the open show is refused with "Kerk is already open" and no hint (`main.rs`). Autosave writes over the
  file whatever changed on disk: `shows.rs` checks modified times only for the `.tmp` of SHW-14. The other half no longer
  holds: a new show gets a Serial node `port: "auto"` on line 1 (`Engine::new`, OUT-25), and the Serial dot turns amber when it
  finds no interface (`MainScreen.protocolDot`); the Art-Net dot is green because Art-Net does send.
- [x] G5: holds. Nothing writes a report. Titan: *Disk › Reports*, fixtures, memories, chases, cue lists, palettes and groups as
  HTML, PDF, CSV or XML, into a Reports folder that opens when done.
- [x] Titan keeps a version of the show per save; CMDMX keeps one `.bak` and the Trash. Not in batch G: `showfile.md`,
  *Out of scope*.
