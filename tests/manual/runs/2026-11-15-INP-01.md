## Found in the run
- The first click on a name right after keypad clicks did nothing: the click arrived with a click count of 3 (the
  keypad clicks counted along), and the first version only typed on a count of 1. Fixed in this PR: with a lone
  number on the line any click types, and only a click within the double-click interval after a typing click is
  dropped. A real mouse resets the count when it moves; the fix holds either way.
- `scripts/app-cpu.sh`: idle 5.8 %, demo 13.4 %; again idle 2.6 %, demo 11.3 %; again idle 1.7 %, demo 8.8 %. The idle
  figure moves between runs as in earlier builds (INP-02: 6.5, 1.5, 4.1); the wheels now observe the command line, which
  changes only on a key.
