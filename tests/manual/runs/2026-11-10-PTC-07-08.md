## Found and fixed in the run
- The Low, High and Offset columns had no headings: the numbers could not be told apart. Now a heading row with `Invert`, `Low %`, `High %`, `Offset %`.
- A refusal message squeezed the row list, so the last row (Zoom) went out of view. The message line is now always reserved.
- **Done** was the default button, so Return in a field would have closed the sheet. It no longer is.
