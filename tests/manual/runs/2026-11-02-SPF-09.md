# Messages sheet run — SPF-09 (2026-11-02)

`tests/manual/app-main-screen.md` *Messages sheet and dots*, at home without lamps. Claude drove the app by computer use, in the
background, and took the screen once for the keyboard lines; no owner steps were done.

Setup: this branch, debug bundle with the engine copied in, app started with `HOME=/tmp/cmdmx-spf09/home -consoleMode NO`, Demo
show, Keys on. Warnings came from the keypad and from a second IPC client. Lightkey was not running. For the `error` and the
reconnect lines the daemon was taken out of the bundle and the app connected to a small stub engine on port 7319: the daemon has
no way to make the app get an `error` without a file dialog, and no way to drop a client and keep its history.

- [x] Empty zone: on a fresh start a click on the zone opens the sheet; Done closes it; Escape closes it.
- [x] Count: `Fixture 999 Enter` shows "nothing is selected" and `1`, again `2`.
- [x] The next command (`Fixture 1 Enter`) clears the line, `2` stays.
- [x] A click on the count opens the sheet, newest first, local time, level, full text. A long line was not available to see wrapping; the text is set to wrap.
- [x] After closing, the count is gone. Two warnings sent over IPC while the sheet was open (`output.add` refused, and a serial node on a missing port) are in the list and left no count.
- [x] Notice: `Group 1 Enter` shows `Group 1` on the line and in the sheet as `notice`; the count stays.
- [x] `say`: Copy on an empty group cell shows its hint on the line, not in the sheet, no count.
- [x] `error` (stub): shown in red as `error` at the local time it arrived (the reply has no `at`), the count rises.
- [x] Node change: a fresh Demo starts with `serial #3 universe 1: Degraded: no interface`, in the list and counted; `serial #5 universe 7: Degraded: port not found` when added. *Ok again* not seen here (no port to bring back); `ipc_52_…` covers the daemon's side and the app shows any notice the same way.
- [x] Reconnect (stub, two connections with an overlapping history): `stub: old warning` once, the new notice added, `Engine offline` and `Engine connected` in order, the count 3 (old warning, error, offline).
- [x] `kill -9` of the engine: `Engine exited (code 9), restarting`, `Engine offline`, `Engine restarted: the show is back, nothing is running`, `Engine connected`; earlier lines stay; count 5, with the new daemon's two node warnings.
- [x] `kill -9` of the app, reopened (adopts): the engine's history with its own times (05:49:46), plus a new `Engine connected`; the earlier app lines are gone.
- [x] Keys on, sheet open: `7` and Space do nothing (the line stays empty), Escape closes the sheet; then `7` types into the line, so Keys was live.
- [x] A click on the Art-Net dot opens the Output screen, on the Control dot (OSC on) the Control screen.
