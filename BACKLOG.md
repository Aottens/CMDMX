# ColourmotionDMX — Backlog

Conventions (from the project-manage skill): one sentence per task with a verifiable done
criterion; T-shirt size (S ≤ 2 h, M ≤ half day, L ≤ day, XL = split it); owner reviews every PR.
Status (the first word of the Status cell, checked by `scripts/check-tracking.py` in CI):
`todo` · `doing` · `done` · `gate3` · `blocked`, details in brackets or after a colon.
- A task PR sets its own row to `done (date, #107)` in the PR itself: **merged = done**. There is
  no `review` or `merged` state; an open PR is visible on GitHub.
- `gate3: <checklist path>` = merged, only the owner's hardware run is left; the path must exist.
- `doing` only for a task that spans several PRs.
- Open points found in a run become their own row (or an IDEA) in the same PR, never a remark
  inside a `done` cell.
