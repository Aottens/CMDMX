# CMDMX manual

This manual is for {{MANUAL_VERSION}}.

CMDMX is a lighting console for macOS. This manual explains how to install it, how it thinks, and
how to run a show with it.

- New here? Start with the [Introduction](introduction.md), then [Getting started](getting-started.md).
- [Concepts](concepts.md) explains the ideas the rest of the manual builds on.
- [Reference](reference.md) has the shortcuts, OSC addresses, file locations and troubleshooting.
- [Release notes](release-notes.md) lists what changed in each version.

Use the search (the magnifier, or press `S`) to find a topic, and the printer icon to print the whole manual or save it as PDF.

Found a mistake? Open an issue on [GitHub](https://github.com/Aottens/CMDMX/issues).
